Site snapshot

Google Analytics · Sep 21–27, 2026 (7-day window)

Traffic nearly doubled again — but the headline conversion number is almost certainly not conversions. Active users 335 → 609 and “key events” 104 → 344, while avg. engagement per user fell 17s → 7s. Every one of the 344 key events is on /contact/, which has no form and no generate_lead call in the code; key events have tracked Contact page views almost 1:1 in every archived week (343 views → 344 key events this week). Read “key events” as “Contact page views” until the GA4 Key Event rule is checked. Deltas marked “vs prior” compare against Sep 14–20 — contiguous and non-overlapping, the first clean week-over-week pair since August. No site code shipped this week (content only: Issue 18, Test #3, jobs refresh), so this is also the first clean read of the redesigned site.

What this window says: the site's reach is growing fast and the redesigned homepage is holding people better than the old one did. But engagement per user is falling (17s → 7s), almost all new traffic is first-visit Google organic from South Asia, and the site's only “conversion” metric appears to count Contact page loads rather than leads. Until subscribe_submit is marked as a Key Event (and the generate_lead rule is checked), there is no trustworthy conversion number on fowl-ai.com.
