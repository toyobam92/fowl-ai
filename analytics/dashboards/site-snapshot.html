GA4 bounce = no 10s+ engagement, no conversion event, no 2nd pageview. 124-user sample, still small — read directionally.

Homepage

Up from 58% last read. Main entry point from Google organic. Add an above-the-fold CTA (subscribe / read latest issue) and internal links to the Jobs Board and Platforms Directory so there's an obvious next click (TICKET-1, still not shipped).

There's no shipped change this cycle that would explain the reversal (see EXPERIMENTS.md and roadmap.md — nothing new shipped since the last review), so the likeliest read is sample noise at this traffic level rather than a real regression — worth watching next cycle before reacting.
