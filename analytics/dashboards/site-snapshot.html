Bounce rate — what to fix, by page

GA4 bounce = no 10s+ engagement, no conversion event, no 2nd pageview. First full 7-day window entirely after TICKET-6 (sitewide event instrumentation) shipped — 94-user sample, still small.

Homepage

Down from 64% last week. Main entry point from Google organic. Add an above-the-fold CTA (subscribe / read latest issue) and internal links to the Jobs Board and Platforms Directory so there's an obvious next click.
