This week

5 developments that show what “agentic” actually costs.

01 / Security

A calendar invite just proved what an AI browser can read.

Security firm Zenity Labs disclosed a flaw it calls “PerplexedBrowser” in Perplexity’s Comet browser: a calendar invite seeded with hidden instructions could direct Comet’s built-in agent to browse local directories, open files, and send the contents to a third-party server, with no click from the user beyond accepting the meeting. Cyberpress reported the flaw was rated critical on Bugcrowd, and that the exposure reached data in a connected 1Password vault. Perplexity’s first attempted fix, shipped January 23, 2026, could still be bypassed; a more complete patch followed on February 13.

Why it matters. Comet’s agent doesn’t cleanly separate “content to summarize” from “instructions to follow” — the same ambiguity sits underneath every agent that reads your inbox, calendar, or files on your behalf. Patching one browser’s version of this doesn’t patch the pattern.

The signal. Zenity says it privately reported the flaw to Perplexity on October 22, 2025 — nearly four months before a fix that actually held.

02 / Security

The Comet bug was the preview. Here’s the whole category.

At Black Hat USA 2026, Zenity Labs demonstrated a broader exploit class it calls “PleaseFix,” built around a technique it names “Intent Collision”: hidden instructions planted in an email, a calendar invite, or an ordinary web page can override what a user actually asked an agent to do, without any click. Dark Reading’s coverage says the demonstrations reached Claude in Chrome, Gemini in Chrome, Perplexity Comet, ChatGPT Atlas, and Copilot Edge. Vendor responses split: some shipped quick fixes, others reportedly treated the behavior as working as designed, and the Cloud Security Alliance’s research note argues no single patch closes the whole class.

Why it matters. If the root cause is architectural rather than a bug in any one product, “which AI browser is safest” is the wrong question for now — the better one is what each vendor actually lets you turn off.

The signal. The CSA traces the common failure to agentic browsers inheriting a user’s logged-in session while processing untrusted page content with no boundary between the two.

03 / Security

Google had its own version — in the calendar, not the browser.

Separately, researchers at Miggo Security found that Gemini could be manipulated through a hidden instruction embedded in a Google Calendar event description, written by someone other than the invite’s recipient. Gemini ingested that description as if it were a legitimate system instruction, which could expose private meeting details to whoever sent the invite. Per Malwarebytes, Google confirmed the finding and mitigated it in January 2026, weeks before the Comet disclosures became public.

Why it matters. This isn’t a scrappy-startup problem. The same category of flaw reached one of the most resourced security teams in the industry, which means “use the big, trusted vendor” isn’t itself a security strategy here.

The signal. Google’s relatively fast turnaround — mitigated within the same reporting cycle — is one of the few clean counterexamples to Perplexity’s two-attempt patch.

04 / Enterprise AI

Enterprises are buying agents faster than they can watch them.

Akto’s inaugural State of Agentic AI Security report, published December 8, 2025 from responses by hundreds of CISOs and security leaders, found 69% of enterprises are already piloting or running AI agents in production, while only 21% have a complete, up-to-date inventory of what those agents and their connected tools can actually access, and 79% lack a governance policy for agent permissions. A CrewAI-sponsored survey of 500 senior executives, published in February, reported that every respondent’s company planned to expand agentic AI use in 2026 — worth reading as a vendor’s own customer base, not a market-wide figure.

Why it matters. The gap between “we deployed it” and “we can see what it did” is exactly the gap the Comet and PleaseFix exploits lived in. Building and documenting that visibility, by hand if the tooling isn’t there yet, is becoming a hireable skill on its own.

The signal. A Dark Reading reader poll closing out 2025 found roughly 48% named agentic AI and autonomous systems the top attack vector heading into 2026 — a readership poll, not a scientific sample, but a consistent signal across multiple write-ups.

05 / Trust

One researcher called it a privacy disaster. Perplexity called it no risk.

Brave’s research team separately tested Comet by hiding instructions invisible to a human reader inside a Reddit post; when Comet’s agent summarized the page, it executed those hidden commands as if they were the user’s own, per ppc.land’s reporting. LayerX separately disclosed a related flaw it named “CometJacking,” in which a single crafted URL with the right query parameters could pull email, calendar, and connected-account data out of the browser. Perplexity’s initial public response to these reports was that it saw “no security impact” and marked them not applicable, before later disabling the exposed MCP API without much public explanation.

Why it matters. When independent researchers and a vendor disagree this sharply about severity, the gap gets absorbed by whoever is actually using the tool — right now, that’s early adopters, not enterprise security teams.

The signal. The disagreement is also a hiring signal: outside researchers are finding and triaging these bugs faster than some vendors acknowledge them — exactly the labor the next section is about.

FOWL prediction 21

By June 30, 2027, at least one major agentic browser vendor will sell a locked-down “enterprise mode” that blocks the agent from acting on untrusted calendar invites, emails, or third-party pages without a separate, logged approval step — as a paid compliance tier, not a universal security patch.

Procurement teams, not individual users, are the ones asking Akto’s visibility question, and 2026 vendors have already shown they’ll ship review and governance features as separately priced tiers rather than free fixes (see last issue’s prediction on review tooling). The PleaseFix research itself argues the underlying flaw can’t be patched away for good, which pushes vendors toward selling a safer mode instead of promising a universal fix. The honest counter-case: a regulator or a high-profile breach could force a free, mandatory fix before any vendor gets to charge for safety.

Put it to work

3 things to do this week.

01

If you or your team already use an agentic browser — Comet, Atlas, Copilot Edge, Gemini in Chrome, Claude in Chrome — check what it’s allowed to read without asking you first, and whether that default is one you actually chose.

02

Audit what’s connected to it: password manager, calendar, email, cloud drive. Disconnect anything you wouldn’t want read by whoever sends the next bad calendar invite.

03

If agent security looks like a career lane worth exploring, start with the public write-ups — Zenity’s and HackerOne’s own breakdowns of these exact exploits are a free, current syllabus.
