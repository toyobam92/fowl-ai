This week

This week: four upgrades and one bill

01 / Agents

OpenAI gave the agent its own computer

At DevDay on September 29, OpenAI introduced “dots,” a new category of always-on agent. In OpenAI’s own description, dots “work 24/7 for you, learn from your feedback, have their own computer, browser and can be connected to over 4k apps in our ecosystem.” They run on Astra, the company’s most capable model, and are bundled into the Pro tier without drawing down usage allowance. Alongside them OpenAI shipped ChatGPT Space and Pages — shared workspaces where a person and a dot work on the same interactive document — plus a public beta of the Agents API and a B2B Marketplace with more than 30 launch partners, Figma and Vercel among them.

Why it matters. The unit of delegation changed. You are no longer sending a message and waiting for a reply; you are handing over a standing assignment to something with its own machine and its own access. That is a management task, not a prompting task, and most people have never been trained for it.

The signal. Dots are included with Pro and do not consume usage allowance. When a vendor removes the meter from a feature, it wants that feature running all day — the pricing tells you the intent more plainly than the keynote does.

02 / Design

The design tool now opens pull requests

Figma’s Config 2026 release put code inside the design canvas. Its Code Layers feature lets teams clone a repository, generate new directions with Figma’s agent, extract running flows into editable design layers, and sync changes back to code. That followed a May release in which Figma Make gained a two-way GitHub integration — import a Git repository into the desktop app, edit the application visually on the canvas, and push the result back through a standard pull request. Figma also shipped an agent-skills system for repeatable custom commands, and was named a launch partner in OpenAI’s new B2B Marketplace last week.

Why it matters. The handoff artifact is disappearing. For twenty years a designer’s output was a file someone else translated; now it can be a commit that enters the same review queue as everyone else’s. If you design, your work is about to be read as code. If you engineer, your review queue just gained a new class of author.

The signal. Those pull requests still run through continuous integration, security checks and code review. Governance did not move — authorship did. That is the quiet pattern in all four of this week’s stories.

Startup Fortune · Figma at Config 2026, June 24, 2026

03 / Memory

Copilot remembers you between tools now

GitHub has enabled Copilot Memory by default for all Copilot Pro and Pro+ users in public preview, so the assistant retains and recalls context between sessions instead of starting cold each time. The more consequential detail is the scope: memories are shared across three surfaces — the coding agent, code review and the CLI — and, as GitHub puts it, “something learned during code review can improve coding suggestions — and vice versa.” Persistent memory also reached the JetBrains plugin in an August release. Individuals can switch it off under Features → Copilot Memory; organization and enterprise admins control it through Copilot policies.

Why it matters. Your accumulated working context — how you name things, which patterns you reject, what your review standards are — is becoming an asset held inside a vendor’s product. That makes it worth asking what happens to it when you change jobs, or when your employer changes tools. Portability is now a career question, not an IT one.

The signal. It is opt-out, not opt-in. Default-on is a statement about where GitHub believes this is heading, and it means most Pro users are already accumulating a memory they never explicitly chose to build.

GitHub community discussion · announced January 15, 2026

04 / Automation

Cron came for the coding agent

On April 16 Anthropic shipped Routines for Claude Code: a saved task “defined by a prompt, connected repositories, and available tools” that can fire on a schedule, through an API call, or in response to a GitHub webhook, running in Anthropic’s cloud rather than on your laptop. Quotas are per day by plan — five on Pro, fifteen on Max, twenty-five on Team and Enterprise. In parallel, Cursor 2.0 went agent-first, running up to eight agents at once and isolating each in its own git worktree so their edits cannot collide until you deliberately merge.

Why it matters. Work can now happen on a calendar you set once and then forget. That is a genuine shift in leverage for anyone running a side project or a small team — and a genuine shift in risk, because output accumulates whether or not anyone is reading it. This newsletter’s own weekly cycle runs on exactly this kind of schedule.

The signal. The constraint is a daily run quota, not a token count. Vendors price infrastructure by the run and chat by the token; the billing model is the clearest signal that scheduled agents are being treated as the former.

05 / The catch

The work that is left over is reading

An analysis of 66,320 Reddit complaint posts about AI coding tools, collected between August 2025 and September 2026 and sorted into 62 named mechanisms, found the top grievance has changed. “Incorrect or buggy code” fell from first place to seventh, with its share of complaints dropping from 13.1% to 9.6%. “Excessive token consumption” rose from ninth to third, climbing from 9.1% to 13.7%. For Cursor specifically, complaints about maintaining the output rose from 5.6% to 9.8% year over year. The report’s summary of the problem is one sentence: “code that arrives faster than it can be reviewed becomes code somebody has to keep.” It lines up with DORA’s 2026 finding that AI acts as an amplifier — teams with solid tests and accessible context gain delivery capacity, while teams with slow reviews and fragile tests get more of the problem they already had.

Why it matters. The complaint moved from “it is wrong” to “it is expensive and I have to maintain it.” That is the signature of a review bottleneck, and it is the part of the job that did not get automated this year. If you want to be valuable next to these tools, be the person whose judgment about what ships is trusted.

The signal. McKinsey’s State of AI 2026, fielded May to June across 1,719 respondents in 97 nations, reports 23% of organizations have scaled an agentic system in at least one business function, 39% are still experimenting, and no more than 10% have scaled agents inside any single function. Treat those three figures as provisional — they come from secondary reporting of the survey, not a direct read of McKinsey’s own page.

From the community

Reading through six months of developer discussion, the tool recommendations have settled into something fairly consistent: Claude Code for difficult work inside a large repository, Cursor for day-to-day editor-led development, and GitHub Copilot for teams that want to stay inside a familiar IDE and GitHub workflow. The framing that keeps recurring is supervisory rather than technical — one developer described the daily reality as managing a junior engineer where you are the senior who checks the work before it ships.

This is reported experience from public forums, not survey data, and the people who post about tools are not a representative sample. Read it as a description of what the work feels like, which is where it is genuinely useful: nobody in these threads describes the job as writing less code. They describe it as reading more.

FOWL prediction 20

By the end of Q1 2027, at least one major coding-agent vendor will ship and separately price a review-side product — a tool whose stated job is helping humans read and accept agent output, not generate more of it.

Vendors build where the complaints are, and the complaint data moved this year: generation quality fell down the list while cost and maintenance burden climbed it. Every incentive now points at the acceptance step, which is the one place the tooling is still thin and the one place a buyer can feel the pain weekly. The honest counter-case is that review is unglamorous and hard to demo, so it may stay a feature inside existing products rather than a priced product of its own — which is why the test below is specifically about separate pricing.

Put it to work

3 things to do this week.

01

Write your acceptance checklist. Pick the one agent you lean on most and write down, in plain words, what you actually verify before you ship its output. Most people have this list in their head and have never read it back to themselves. It is the clearest statement of what your judgment adds, and it is the thing to put in front of a manager who asks what you do that the tool does not.

02

Audit what a vendor remembers about you. If you are on Copilot Pro or Pro+, memory is on unless you turned it off — look under Features → Copilot Memory and see what is there. Decide deliberately whether you want that context accumulating inside a product you may not be using in two years, and find out now whether it can leave with you.

03

Put exactly one recurring chore on a schedule. A dependency sweep, a weekly summary, a stale-branch check — something small and verifiable. Then measure the thing most people skip: did it save you time, or did it generate output you now have to read every week? That answer is the whole lesson of this issue, at a scale where it costs you nothing to learn it.

Career radar

Agent orchestration engineer

The role that designs and maintains how multiple agents are wired into a real workflow: which tools each can reach, what runs on a schedule, where a human sign-off is mandatory, and what happens when one of them fails quietly at 3am. It sits between platform engineering and operations, and it exists because the four stories above created a coordination problem that nobody owned. Postings appear under several names — agentic workflow engineer, AI automation specialist, agent orchestration engineer — which is the usual sign of a role that is real but not yet standardized.

A place to start. ZipRecruiter put average advertised pay for “AI orchestration” roles at about $148,000 as of mid-2026; treat aggregator averages as a rough band, not a number to negotiate against. The most credible way in is a working artifact: one scheduled, multi-step agent workflow with a human approval gate and a written record of what it does when something breaks. That is a portfolio piece you can build in a weekend, and it demonstrates exactly the judgment the job is actually for.

Know where to look.

The evaluation-and-training side of the market is where the money is most visible right now, and the specialist tier is where it concentrated. Every story this week is a tool taking on more of the work: its own machine, its own memory, its own schedule, its own seat at the table. Read in a row, they look like a story about things being taken away. I do not think that is what they are. What all four have in common is that they shift the human contribution from producing the work to deciding whether the work is any good — and the complaint data suggests almost nobody has staffed for that yet. Twenty issues ago I thought the interesting question was which jobs AI would replace. The more useful question turned out to be which judgments stay with people, and whether those people are given the time to actually make them.
